# Повний посібник із захисту сайту USSF 2026 від DDoS-атак через Cloudflare

У коді сайту вже активовано **внутрішній багаторівневий захист** (Cloudflare Turnstile CAPTCHA, Honeypot-пастка для ботів, Time-lock та IP Rate Limiting).

Щоб захистити сам сервер та домен від **мережевих (об'ємних) DDoS-атак** (коли ботнети намагаються «покласти» хостинг мільйонами запитів), підключіть домен до **безкоштовного тарифу Cloudflare (Free Tier)**.

---

## Чому Cloudflare Free?
- **100% Безкоштовно** назавжди для будь-якого сайту.
- **Необмежений захист від L3/L4/L7 DDoS-атак** (Cloudflare поглинає терабітні атаки ще на своїх глобальних серверах).
- **Приховування IP-адреси вашого сервера** (зловмисники бачать лише IP Cloudflare, тому не можуть атакувати сервер напряму).
- **Безкоштовний SSL/TLS сертифікат** (HTTPS) та прискорення завантаження сайту через глобальний CDN.

---

## Крок 1. Реєстрація та додавання сайту в Cloudflare

1. Перейдіть на офіційний сайт [cloudflare.com](https://www.cloudflare.com/) та зареєструйте безкоштовний акаунт (Sign Up).
2. Натисніть **«Add a Domain»** (Додати домен) або **«Add Site»**.
3. Введіть назву вашого домену (наприклад, `ussf.org.ua` або `ussf-surgery.com`).
4. На екрані вибору тарифу прокрутіть вниз і виберіть **«Free» ($0 / month)** та натисніть **Continue**.

---

## Крок 2. Перевірка DNS-записів

1. Cloudflare автоматично просканує ваші поточні DNS-записи.
2. Переконайтеся, що навпроти основного запису (A або CNAME, який вказує на ваш сервер / Render / GitHub Pages) увімкнено **помаранчеву хмарку**:
   - Статус: **Proxied** (Помаранчева хмарка 🟠).
   - *Це означає, що весь трафік тепер фільтрується через захисний екран Cloudflare.*

---

## Крок 3. Зміна NS-серверів у реєстратора домену

1. Cloudflare надасть вам два персональні NS-сервери, наприклад:
   - `alec.ns.cloudflare.com`
   - `becky.ns.cloudflare.com`
2. Зайдіть в панель керування вашого реєстратора домену (де купували домен, наприклад: nic.ua, namecheap, godaddy, hostinger тощо).
3. Знайдіть розділ **«NS-сервери»** (Nameservers) та замініть старі записи на два сервери від Cloudflare.
4. Збережіть зміни. Протягом 10–30 хвилин домен почне працювати через Cloudflare.

---

## Крок 4. Увімкнення трьох ключових захисних перемикачів у Cloudflare

Після активації домену перейдіть у панель Cloudflare вашого сайту:

### 1. Bot Fight Mode (Миттєве відсікання 99% ботів)
- Перейдіть: **Security** → **Bots**.
- Увімкніть тумблер **«Bot Fight Mode»**: **ON**.
- *Ефект: Cloudflare автоматично аналізує поведінку запитів та відсікає відомі ботнети, шкідливі сканери та спам-скрипти без навантаження на ваш сервер.*

### 2. Захист від масованих атак («Under Attack Mode»)
- На головній сторінці сайту (Overview) у правому блоці є перемикач **«Under Attack Mode»**.
- **У звичайний час**: тримайте його **OFF** (стандартний захист Cloudflare працює автоматично).
- **Якщо на вас почалася сильна атака**: переведіть у **ON**. Cloudflare увімкне обов'язкову 3-секундну фонову перевірку браузера для 100% відвідувачів, повністю блокуючи будь-який флуд.

### 3. Налаштування SSL/TLS шифрування
- Перейдіть: **SSL/TLS** → **Overview**.
- Виберіть режим: **Full** або **Full (strict)**, щоб весь трафік між користувачем, Cloudflare та вашим сервером був захищений.

---

## Крок 5. Як отримати власні бойові ключі Cloudflare Turnstile

У коді сайту вже встановлено офіційні тестові ключі. Щоб підключити свої власні персональні ключі:
1. У панелі Cloudflare у лівому меню натисніть **Turnstile**.
2. Натисніть **«Add Site»**:
   - Site name: `USSF Registration Form`
   - Domain: введіть ваш домен (або `localhost` для тестів)
   - Widget Mode: виберіть **Managed** (рекомендовано — інтелектуальний режим)
3. Натисніть **Create**.
4. Ви отримаєте два ключі:
   - **Site Key** (Публічний ключ, наприклад: `0x4AAAAAA...`)
   - **Secret Key** (Секретний ключ, наприклад: `0x4AAAAAA...`)
5. Вставте їх у файл `email_config.json`:
   ```json
   "turnstile_site_key": "ВАШ_SITE_KEY",
   "turnstile_secret_key": "ВАШ_SECRET_KEY"
   ```
6. У `index.html` замініть `data-sitekey="1x00000000000000000000AA"` на ваш новий `Site Key`.
