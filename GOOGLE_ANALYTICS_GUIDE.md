# 📊 Посібник з налаштування та використання Google Analytics 4 (GA4) для USSF

Цей посібник детально пояснює, як активувати Google Analytics 4 на сайті конгресу, як переглядати статистику відвідувань у реальному часі, оцінювати реєстрації та читати звіти.

---

## 1. Як отримати свій безкоштовний ідентифікатор (Measurement ID)

Google Analytics надається безкоштовно компанією Google. Щоб підключити його:

1. Перейдіть на офіційний сайт: [analytics.google.com](https://analytics.google.com) та увійдіть під своїм Google-акаунтом (Gmail).
2. Натисніть кнопку **"Почати вимірювання"** (Start measuring).
3. **Назва облікового запису (Account name):** Введіть, наприклад, `USSF Forum` або `НМУ Хірургія`.
4. **Налаштування ресурсу (Property setup):**
   - Назва ресурсу: `USSF Website`.
   - Часовий пояс: `Україна (Київ, GMT+2 / GMT+3)`.
   - Валюта: `Українська гривня (UAH)` або `USD`.
5. **Відомості про компанію:** Оберіть галузь (наприклад, "Охорона здоров'я" або "Освіта") та розмір (1–10 працівників).
6. **Цілі бізнесу:** Оберіть "Збір даних про потенційних клієнтів" (Generate leads) та "Вимірювання взаємодії із сайтом".
7. **Вибір платформи для збору даних:**
   - Оберіть **Веб (Web)**.
   - Введіть URL вашого сайту (або домен, якщо вже є, наприклад `ussf.nmu.ua`, або тимчасовий).
   - Назва потоку: `USSF Landing Page`.
   - Натисніть **"Створити потік"** (Create stream).
8. У вікні, що з'явиться, ви побачите **Ідентифікатор потоку даних (Measurement ID)**.
   - Він виглядає як: `G-XXXXXXXXXX` (літера `G-` і 10 символів). Скопіюйте його!

## 2. Як підключити ваш ID до сайту

Усі скрипти та події вже вбудовані в код сайту. Потрібно лише вказати ваш унікальний `G-XXXXXXXXXX`:

### Спосіб А: У файлі `index.html` (Основний і постійний спосіб)
Відкрийте `index.html` і знайдіть рядки 24 та 30:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX" id="gaTagScript"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  const gaMeasurementId = localStorage.getItem('ussf_ga_id') || 'G-XXXXXXXXXX';
  gtag('config', gaMeasurementId, {
    send_page_view: true
  });
</script>
```
Замініть обидва `G-XXXXXXXXXX` на ваш реальний ID (наприклад, `G-7K9ABC1234`).

### Спосіб Б: Без редагування коду (Швидкий тест через браузер)
Якщо ви хочете перевірити прямо зараз на локальному комп'ютері:
1. Відкрийте сайт у браузері.
2. Натисніть `F12` -> вкладка **Console**.
3. Введіть:
   ```javascript
   localStorage.setItem('ussf_ga_id', 'G-ВАШ_РЕАЛЬНИЙ_ID');
   location.reload();
   ```
   Сайт автоматично почне надсилати події у ваш GA4!

## 3. Які події сайт вже автоматично фіксує

У код додано трекінг ключових дій користувачів (Custom Events):

| Назва події в GA4 | Що вона означає | Додаткові дані, які передаються |
| :--- | :--- | :--- |
| `page_view` | Перегляд сторінки сайту | URL, заголовок сторінки, пристрій |
| `registration_modal_open` | Клік по кнопці «Зареєструватися» | Джерело кліку (шапка, банер, секція реєстрації) |
| `registration_preview_step` | Натискання «Перевірити» перед подачею | Чи переглянув користувач прев'ю заяви |
| `registration_success` | **Головна конверсія:** успішна відправка анкети! | `submission_id`, `section` (секція тез), `participation_format` (очно/онлайн) |
| `program_day_select` | Перемикання днів у секції «Програма» | `day_number` (1 або 2) |
| `program_track_select` | Вибір секції програми (Травма / Онко / Невідкладна) | `track_id` (track-trauma, track-emergency, track-onco) |
| `floor_plan_switch` | Перегляд плану локації | `floor` (1 або 2 поверх) |
| `language_switch` | Перемикання мови сайту | `language` (ua або en) |
| `map_navigation_click` | Клік по навігації до локації | `provider` (Google Maps або Waze) |
| `telegram_click` | Перехід до офіційного Telegram-каналу форуму | URL посилання |

## 4. Як користуватися звітами Google Analytics 4

У кабінеті GA4 зліва є меню з розділами. Ось 5 найважливіших звітів:

### 1. Звіт «В реальному часі» (Realtime)
- **Де знайти:** Зліва меню -> **Звіти (Reports)** -> **У реальному часі (Realtime)**.
- **Що показує:** Хто зараз на сайті (за останні 30 хвилин).
- **Як перевірити працездатність:**
  1. Відкрийте сайт на телефоні або в іншій вкладці.
  2. Зайдіть у розділ Realtime у кабінеті GA.
  3. Ви побачите синю точку на мапі (Київ або ваше місто) та лічильник «1 користувач».
  4. Натисніть «Зареєструватися» на сайті — у картці «Кількість подій за назвою» миттєво з'явиться `registration_modal_open`!

### 2. Джерела трафіку (Traffic acquisition) — Звідки приходять люди
- **Де знайти:** **Звіти** -> **Життєвий цикл** -> **Джерела трафіку (Acquisition)** -> **Залучення трафіку**.
- **Що показує:**
  - `Direct` — прямі заходи (ввели адресу вручну або зберегли в закладки).
  - `Organic Social` — переходи з Instagram, Facebook, Telegram.
  - `Organic Search` — пошук у Google.
  - `Referral` — переходи з сайтів університетів чи партнерів.
- **Порада:** Ви одразу бачите, з якого каналу люди не просто приходять, а реально реєструються.

### 3. Події та Конверсії (Events & Conversions)
- **Де знайти:** **Звіти** -> **Взаємодія (Engagement)** -> **Події (Events)**.
- Тут відображається весь список: скільки разів відкривали програму, скільки людей переглянули прев'ю тез, скільки натиснули на карту.
- **Як призначити конверсію:**
  1. Перейдіть у лівому нижньому кутку в **Адміністратор (Admin ⚙️)** -> **Події (Events)**.
  2. Знайдіть у списку подію `registration_success`.
  3. Увімкніть перемикач **"Позначити як конверсію"** (Mark as conversion).
  4. Тепер успішна реєстрація вважатиметься головною цільовою дією сайту!

### 4. Демографія та Географія (Demographics)
- **Де знайти:** **Звіти** -> **Користувач** -> **Демографічні дані**.
- Показує міста України та інші країни, звідки цікавляться хірургічним форумом (Київ, Львів, Харків, Дніпро, Одеса тощо).

### 5. Пристрої (Tech / Devices)
- **Де знайти:** **Звіти** -> **Користувач** -> **Технічні дані**.
- Показує співвідношення: скільки % користувачів заходять з телефонів (Mobile), а скільки з комп'ютерів (Desktop). Це допомагає зрозуміти, як покращувати мобільну версію.

## 5. Професійна порада: UTM-мітки для посилань

Коли ви публікуєте посилання на реєстрацію в різних каналах (Telegram-канал, Instagram-сторінка, розсилка деканату), додавайте **UTM-мітки**, щоб Google Analytics чітко розрізняв джерела.

Приклади готових посилань:
- **Для Telegram-каналу форуму:**
  `https://ваш-домен/?utm_source=telegram&utm_medium=channel_post&utm_campaign=reg_open`
- **Для Instagram Stories:**
  `https://ваш-домен/?utm_source=instagram&utm_medium=stories&utm_campaign=reg_open`
- **Для університетського чату/групи:**
  `https://ваш-домен/?utm_source=student_council&utm_medium=chat&utm_campaign=invite`

У звіті «Залучення трафіку» GA4 покаже окремий рядок для кожного з цих посилань, і ви точно знатимете, яка публікація принесла найбільше зареєстрованих учасників!
